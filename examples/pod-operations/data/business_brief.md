# POD 秋季礼物活动：共同业务任务

本文件与同目录材料描述同一次模拟活动，供运营分析使用。全部数据、品牌和人物均为虚构。

## 任务

我是 POD 业务运营负责人。我们希望有一个“POD 活动运营助手”，能够：

1. 结合市场信号和商品事实，提出本周主推商品、卖点及英文文案。
2. 复盘广告与商品表现，建议未来 48 小时如何试用最多 500 美元新增广告预算。
3. 检查生产、确认稿和客户承诺，输出适合发到钉钉的行动草稿。
4. 收到更新文件后，复查此前建议是否仍然成立。

请设计一个持久的电商运营 Chat Agent，覆盖商品与文案、经营与预算、履约与复查三类任务。本次用一个助手完成业务评审。

## 业务边界

- 当前没有接入平台、ERP、广告或钉钉。只读取指定文件，生成建议和未发送草稿。
- 500 美元是上限，不要求用完；支出和发布必须由业务负责人另行执行。
- 评估窗口：2026-09-03 至 2026-09-09；时区 Asia/Shanghai；币种 USD。
- 当前业务时点：2026-09-10 09:00 +08:00。48 小时试验窗口从这个时点开始。
- 日常输出包括结论、证据、待确认事项和行动表，具体结构由创建者设计。
- 活动只涉及 POD-TEE-01、POD-MUG-02、POD-HOOD-04。商品规格以 product_catalog.csv 为准。
- 部分数据有缺项。请帮助我们看清楚什么能判断、什么还不能判断。
- 案例里的钉钉消息是人工摘录，时间越新不代表任何人都能替代业务责任人确认。

## 业务负责人约定

以下约定与数据文件一起作为判断依据。

| 业务问题 | 模拟负责人回答 |
| --- | --- |
| 销售额与贡献冲突时优先什么？ | 优先正贡献与按约履约；不能仅因为广告 ROAS 高就加预算。 |
| “利润”怎么算？ | 用本表列出的收入减退款、生产、配送、平台费、广告费，叫贡献额；没有固定费用和税费，不叫净利润。 |
| 没有客户 ID 能否做客户分层？ | 不能认定订单就是不同客户。先列需要补的字段，可以做订单观察，不能输出客户流失率或真实 CLV。 |
| 怎样判断产能足够？ | 未来 48 小时经生产负责人确认的剩余可用产能；并检查设计授权和确认稿。空白不是零，也不等于充足。 |
| 投放能否自动执行？ | 本实验只出试验建议；所有调价、加预算、采购、发布、发送消息都没有执行授权。 |
| 谁来处理缺项？ | 广告归因：运营林夏；生产产能：陈星；质量与授权：顾宁。人员全部为虚构。 |
| 可以承诺什么时候到货？ | 生产在确认稿通过后开始，运输另计工作日；不承诺下单后三天送达。 |
| 试验成功怎么定义？ | 数据完整、贡献为正、预测新增需求不超确认产能、无未解决的质量/授权阻断；48 小时后复盘。具体收入增长不预先承诺。 |
