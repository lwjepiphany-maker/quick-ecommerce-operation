# 指标与口径

全部为模拟数据。`campaign_performance.csv` 每一行是一个 SKU 在完整七天窗口内的聚合；三行不是三笔订单。不要把 SKU 聚合行当成订单明细。

- `gross_sales_usd`：该 SKU 全渠道销售额，退款前。
- `refund_amount_usd`：同窗口列示退款金额；简单教学口径，不表示已完成会计收入确认。
- `production_cost_usd`、`shipping_cost_usd`、`platform_fee_usd`：窗口成本，分别列示，不能遗漏或重复扣除。
- `ad_spend_usd`：该窗口广告花费。
- `attributed_ad_sales_usd`：广告归因销售额，非总销售额。本例不同 SKU 使用一致的教学归因窗口；真实数据需另外核对归因设置。
- `attributed_orders`：广告归因订单数，用于 CPA；不是客户数。
- `attribution_status=partial`：归因数据未齐，即使总销售额已知也不能补作广告归因销售额。
- 净销售额 = 销售额 − 退款。
- 贡献额 = 销售额 − 退款 − 生产成本 − 配送成本 − 平台费 − 广告花费。
- 贡献率 = 贡献额 / 净销售额；净销售额为零或非正时标记不可正常解释。
- ROAS（广告支出回报率） = 广告归因销售额 / 广告花费；ACOS（广告销售成本比） = 广告花费 / 广告归因销售额。
- CPA（本例为每个广告归因订单的广告成本） = 广告花费 / 广告归因订单数。分母缺失或零时不得硬算。
- 退款金额率 = 退款金额 / 总销售额，不能称为“退款订单率”。
- 预算 / 历史 CPA 只能作为新增归因订单的粗略情景，不是增量因果预测，更不是销量保证。
- `capacity_48h_units` 是新增活动可用的生产位，不是成品库存，不需要套用成品库存 EOQ。
- 即使有历史 CPA，产能受限、质量未放行或归因缺失，也不能机械加预算。
- 引用格式：文件名 + SKU/消息 ID + 窗口或时间；把事实、假设、建议分开。

CLV（客户终身价值）需要客户级历史数据与明确的预测口径，本例 SKU 汇总数据不足以计算。订单数不能替代客户数。
